# RP — CRMP Mobile RolePlay (open.mp)

Игровой мод для сервера **CRMP Mobile** на базе **open.mp** (Pawn, MySQL).

## Основа

Код взят из открытого проекта
[rezzylrn/openmp-nusantara-roleplay](https://github.com/rezzylrn/openmp-nusantara-roleplay)
под лицензией **MIT** (см. `LICENSE`, копирайт автора обязательно сохраняем).
Мод модульный (~60 файлов, ~22 тыс. строк), с bcrypt-паролями, MySQL R41,
античитом, работами, фракциями, транспортом, домами, телефоном и инвентарём.

## Структура

```
gamemodes/
  main.pwn        — точка входа
  core/           — БД, авторизация, диалоги, события, локализация
  anticheat/      — античит
  ui/             — HUD, спидометр, прогресс-бар, радиальное меню
  systems/        — экономика, инвентарь, дома, транспорт, магазины и т.д.
  gameplay/       — фракции, работы, телефон, полиция
  commands/       — команды игроков и админов
qawno/include/    — инклуды (open.mp, a_mysql, sscanf2, izcmd, bcrypt, easyDialog)
database.sql      — структура базы MySQL/MariaDB
config.json       — конфиг сервера open.mp
```

## Режим «Дикий Запад» (`gamemodes/gameplay/wild_west.inc`)

Собственный вестерн-режим поверх RP: дуэли, награды за голову, честь, лошади,
охота и ограбления дилижансов. Справка в игре — `/ww`.

| Команда | Что делает |
|---|---|
| `/duel [id] [ставка]`, `/duelaccept`, `/dueldecline` | Дуэль на револьверах (до 20 м, отсчёт 3-2-1, 60 сек, победитель забирает банк) |
| `/bounty [id] [сумма]` | Назначить награду за голову (деньги вносятся сразу) |
| `/bounties` | Доска «Разыскивается» |
| `/payfine` | Погасить розыск шерифа (в офисе шерифа) |
| `/honor` | Честь (-100..100), статистика. Честь влияет на цены |
| `/horse` | Конюшня: взять лошадь, подозвать свистом, отпустить |
| `/hunt` | Охота в угодьях (винтовка/дробовик в руках) |
| `/buyrifle`, `/sellpelts` | Фактория: винтовка, продажа шкур и мяса |
| `/deadeye` | «Меткий глаз»: +50% урона из огнестрела на 10 сек (перезарядка 3 мин) |
| `/robcoach` | Ограбить дилижанс (событие раз в ~25 мин, шериф получает метку) |
| `/wwcoach` | Админ (3+): вызвать дилижанс сразу |

Правила закона: убийство невиновного — розыск +$250 и минус честь; убийство
разыскиваемого — охотник получает частную награду плюс розыск шерифа,
взысканный из кармана преступника (деньги из воздуха не появляются).
Шериф — фракция полиции на службе (`/duty`).

Настройки (цены, таймеры, модель «лошади», координаты) — блок `#define` в начале
файла. Координаты сейчас указывают на Форт-Карсон (карта SA); при переходе на карту
CRMP меняются только они. В SA нет лошадей, поэтому `WW_HORSE_MODEL` по умолчанию —
квадроцикл; при наличии кастомной модели лошади впишите её ID.

## Сборка

Нужен компилятор [open.mp Pawn compiler 3.10](https://github.com/openmultiplayer/compiler/releases):

```
cd gamemodes
pawncc main.pwn -i../qawno/include -d3
```

Сервер: [open.mp server](https://github.com/openmultiplayer/open.mp/releases) + плагины
`mysql` (R41-4), `samp_bcrypt`, компонент `sscanf`.
